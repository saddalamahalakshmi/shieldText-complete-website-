    Spot the warning signs

    Use these simple checks whenever an unexpected message arrives.

    ↗

    Unexpected links

    Check the sender and website address carefully. Do not open shortened or unfamiliar links just because a message creates urgency.

    LINK SAFETY
    !

    Urgent pressure

    Messages saying “act now” or threatening account closure may be trying to stop you from thinking carefully.

    URGENCY
    ♙

    Private information

    Never share passwords, PINs, or one-time passwords in response to a message or an unexpected call.

    PRIVACY
    ✓

    Verify independently

    Contact the organization using its official app, website, or a known phone number—not the details inside a suspicious message.

    ABOUT THE PROJECT

    Small checks. Safer choices.

    ShieldText is a student website project demonstrating how a web interface can analyze text, present explainable warning signs, and store a local history of results.

    It uses HTML for structure, CSS for responsive styling, and JavaScript for rule-based analysis and browser storage.
